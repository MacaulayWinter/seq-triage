# Citations

seq-triage is built on the tools below. If you use it, please cite them.
Exact versions used in a run are in `pipeline_info/software_versions.tsv`.

## Pipeline framework

- **Nextflow**: Di Tommaso P, et al. (2017) Nextflow enables reproducible
  computational workflows. *Nature Biotechnology*.
  [doi:10.1038/nbt.3820](https://doi.org/10.1038/nbt.3820)
- **nf-core**: Ewels PA, et al. (2020) The nf-core framework for
  community-curated bioinformatics pipelines. *Nature Biotechnology*.
  [doi:10.1038/s41587-020-0439-x](https://doi.org/10.1038/s41587-020-0439-x)

## Tools

- **SeqKit**: Shen W, et al. (2016) SeqKit: a cross-platform and ultrafast
  toolkit for FASTA/Q file manipulation. *PLOS ONE*.
  [doi:10.1371/journal.pone.0163962](https://doi.org/10.1371/journal.pone.0163962)
- **fastp**: Chen S, et al. (2018) fastp: an ultra-fast all-in-one FASTQ
  preprocessor. *Bioinformatics*.
  [doi:10.1093/bioinformatics/bty560](https://doi.org/10.1093/bioinformatics/bty560)
- **FastQC**: Andrews S. (2010) FastQC: a quality control tool for high
  throughput sequence data.
  [bioinformatics.babraham.ac.uk](https://www.bioinformatics.babraham.ac.uk/projects/fastqc/)
- **NanoPlot**: De Coster W, Rademakers R. (2023) NanoPack2:
  population-scale evaluation of long-read sequencing data. *Bioinformatics*.
  [doi:10.1093/bioinformatics/btad311](https://doi.org/10.1093/bioinformatics/btad311)
- **MultiQC**: Ewels P, et al. (2016) MultiQC: summarize analysis results for
  multiple tools and samples in a single report. *Bioinformatics*.
  [doi:10.1093/bioinformatics/btw354](https://doi.org/10.1093/bioinformatics/btw354)
- **Kraken 2**: Wood DE, Lu J, Langmead B. (2019) Improved metagenomic
  analysis with Kraken 2. *Genome Biology*.
  [doi:10.1186/s13059-019-1891-0](https://doi.org/10.1186/s13059-019-1891-0)
- **Bracken**: Lu J, Breitwieser FP, Thielen P, Salzberg SL. (2017) Bracken:
  estimating species abundance in metagenomics data. *PeerJ Computer Science*.
  [doi:10.7717/peerj-cs.104](https://doi.org/10.7717/peerj-cs.104)
- **SAMtools**: Danecek P, et al. (2021) Twelve years of SAMtools and
  BCFtools. *GigaScience*.
  [doi:10.1093/gigascience/giab008](https://doi.org/10.1093/gigascience/giab008)
- **SortMeRNA**: Kopylova E, Noé L, Touzet H. (2012) SortMeRNA: fast and
  accurate filtering of ribosomal RNAs in metatranscriptomic data.
  *Bioinformatics*.
  [doi:10.1093/bioinformatics/bts611](https://doi.org/10.1093/bioinformatics/bts611)
- **NCBI genome size table**: expected genome sizes per species, from NCBI's
  genome size check (`genomes/ASSEMBLY_REPORTS/species_genome_size.txt`),
  used for the depth-of-coverage estimate.
- **R**: R Core Team. R: A language and environment for statistical
  computing. R Foundation for Statistical Computing, Vienna, Austria.
  [r-project.org](https://www.r-project.org/)

## Software packaging

- **Bioconda**: Grüning B, et al. (2018) Bioconda: sustainable and
  comprehensive software distribution for the life sciences. *Nature
  Methods*. [doi:10.1038/s41592-018-0046-7](https://doi.org/10.1038/s41592-018-0046-7)
- **BioContainers**: da Veiga Leprevost F, et al. (2017) BioContainers: an
  open-source and community-driven framework for software standardization.
  *Bioinformatics*. [doi:10.1093/bioinformatics/btx192](https://doi.org/10.1093/bioinformatics/btx192)
